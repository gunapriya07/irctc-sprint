
# IRCTC Sprint: Feature Specifications and Solution Design

This repository documents the full product sprint for improving the IRCTC user experience. It includes:

- Six detailed feature specifications addressing the most critical pain points from Part A
- Wireframes and UI mockups for all user-facing changes
- An AI feature proposal targeting a key IRCTC problem
- An Impact vs Effort matrix with justifications for all solutions
- Peer review updates and rationale

All documentation is structured to directly reference the original problems and user flows discovered in Part A. See part-b/SPECS.md for full feature specs, and assets/wireframes/ for UI wireframes.
